## Responsive Design

The portfolio was developed following a **Mobile First** approach.

The navigation adapts according to the screen size:

- **Mobile:** hamburger menu with a horizontally displayed collapsible navigation.
- **Tablet:** navigation links are displayed horizontally without the hamburger button.
- **Desktop:** navigation links are displayed horizontally without the hamburger button.

The rest of the portfolio also adapts its layout to different screen sizes, including the technologies, projects, and personal information sections.

## Accessibility

Accessibility was considered during the development of the navigation system.

The hamburger menu button uses ARIA attributes to communicate its state to assistive technologies:

- `aria-label`
- `aria-expanded`
- `aria-controls`

Focus states were also included to improve keyboard navigation.
